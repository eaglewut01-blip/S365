# ภาพบรรยากาศ/สถานที่ (Facility Photos)

ภาพรวมของยิม ถ่ายกว้าง ใช้เป็นพื้นหลัง Hero หรือหน้า "เกี่ยวกับเรา" — โฟลเดอร์นี้เป็นโบนัส
(ผู้ใช้ไม่ได้ระบุไว้ตอนแรก แต่เว็บยิมที่ดีมักต้องมีภาพแนวนี้ ถ้ามีให้วางที่นี่ ถ้าไม่มีข้ามไปได้)

- สัดส่วน: **16:9 กว้างมาก** ถ่ายช่วงไม่มีคนเยอะ แสงสวย (เช้า/เย็น)
- มุมที่เห็นภาพรวมทั้งโซน ไม่ใช่มุมแคบ
- ถ่ายทางเข้า/โลโก้หน้าร้านด้วยอย่างน้อย 1 ภาพ (ใช้ได้หลายที่: แผนที่, นามบัตรดิจิทัล, Google Maps)
