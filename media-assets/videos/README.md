# คลิปวิดีโอ (Video Clips)

วางคลิปวิดีโอทุกประเภทที่นี่ — ไฟล์จากกล้อง/มือถือตรงๆ ได้เลย ไม่ต้องตัดต่อ/บีบอัดเอง

## ประเภทที่ควรมี

| ประเภท | ความยาวที่แนะนำ | ใช้ตรงไหน |
|---|---|---|
| วิดีโอพื้นหลัง Hero | 10–20 วินาที, วนลูปได้ | พื้นหลังหน้าแรกเว็บ (เงียบ ไม่มีเสียง) |
| คลิปแนะนำคลาส | 30–90 วินาที | หน้าแต่ละคลาส/โปรแกรม |
| คลิปแนะนำเทรนเนอร์ | 30–60 วินาที | หน้าโปรไฟล์เทรนเนอร์ |
| คลิป testimonial ลูกค้า | 30–60 วินาที | หน้า "รีวิว"/ความสำเร็จ |
| ทัวร์สถานที่ | 1–3 นาที | หน้า "เกี่ยวกับเรา" |

- ถ่ายแนวนอน (16:9) เป็นหลัก — ถ้าจะเอาไปลง Instagram/TikTok ด้วยให้ถ่ายแนวตั้ง (9:16) แยกอีกชุด
- วิดีโอพื้นหลัง Hero **ห้ามมีเสียงพูด** (เบราว์เซอร์บล็อกเสียงอัตโนมัติอยู่แล้ว ต้องดูรู้เรื่องแบบเงียบ)
- ถ่ายนิ่ง ใช้ขาตั้งถ้ามี กล้องสั่นมากจะดูไม่เป็นมืออาชีพ
