# ภาพเดี่ยว (Individual / Action Photos)

ภาพคนกำลังออกกำลังกายจริง (ลูกค้า, เทรนเนอร์ขณะสอนตัวต่อตัว, โมเมนต์ระหว่างคลาส) — ภาพกลุ่มนี้คือ
ภาพที่ "ขาย" ความรู้สึกของยิมได้มากที่สุด ใช้เป็น Hero/แบนเนอร์หลักและโพสต์โซเชียล

- ถ่ายทั้ง **แนวตั้ง (4:5 หรือ 9:16)** และ **แนวนอน (16:9)** ของโมเมนต์เดียวกันถ้าทำได้
  - แนวนอนกว้าง → ใช้เป็น Hero บนเว็บ (จอคอม)
  - แนวตั้ง → ใช้บนมือถือ/Instagram/Facebook Story
- แสงธรรมชาติหรือแสงยิมจริงดีกว่าไฟสตูดิโอจัดเต็ม — ให้ดูสมจริง ไม่ใช่ภาพสต็อก
- เน้นช่วง**กำลังเคลื่อนไหว** (ชกมวย, ยกน้ำหนัก, หมดแรงหลังคลาส) มากกว่าโพสต์ยืนยิ้มนิ่งๆ
- ถ้าเป็นภาพลูกค้า **ต้องขออนุญาตก่อนนำไปใช้บนเว็บ/โซเชียลเสมอ** (ด้านกฎหมาย/ความเป็นส่วนตัว)
