# ภาพเทรนเนอร์ (Trainer Photos)

วางภาพเทรนเนอร์แต่ละคนที่นี่ — 1 คนควรมีอย่างน้อย 2 แบบ:

1. **ภาพหน้าตรง (headshot/portrait)** — สำหรับใช้เป็นไอคอนกลม/สี่เหลี่ยมในรายการทีมงาน
   - สัดส่วน: **1:1 (สี่เหลี่ยมจัตุรัส)**
   - ถ่ายจากอกขึ้นไป พื้นหลังเรียบหรือเบลอ, แสงหน้าชัด ไม่ย้อนแสง
2. **ภาพบุคลิก/ขณะสอน (action/bio shot)** — สำหรับการ์ดโปรไฟล์เต็ม หรือหน้า "รู้จักเทรนเนอร์"
   - สัดส่วน: **4:5 (แนวตั้ง)** หรือ **3:2 (แนวนอน)** ก็ได้ แล้วแต่ท่าถ่าย
   - ขณะกำลังสอน/โค้ชจริง ดูเป็นธรรมชาติ ดีกว่าโพสต์นิ่งเกินไป
