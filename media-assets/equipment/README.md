# ภาพเครื่อง/อุปกรณ์ (Equipment Photos)

ภาพเครื่องออกกำลังกายและอุปกรณ์ในยิม — ใช้ประกอบการ์ดคลาส/หน้าแนะนำสิ่งอำนวยความสะดวก

- สัดส่วน: **4:3 หรือ 16:9 (แนวนอน)** — ถ่ายให้เห็นบริบทรอบๆ ด้วย ไม่ใช่ถ่ายชิดเครื่องอย่างเดียว
  (มุมกว้างพอเห็นพื้นที่ใช้งานจริง ดูน่าเชื่อถือกว่า)
- ถ่ายตอนไฟเปิดครบ ไม่มีของรกวางอยู่ใกล้ๆ
- ถ้ามีคนกำลังใช้เครื่องอยู่ (ไม่ใช่แค่เครื่องเปล่า) จะดูมีชีวิตชีวากว่ามาก แนะนำให้ถ่ายคู่กันไว้ทั้งสองแบบ
