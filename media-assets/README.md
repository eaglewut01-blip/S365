# คลังสื่อ (Media Assets) — คู่มือจัดเก็บไฟล์

โฟลเดอร์นี้คือที่พักไฟล์ภาพ/วิดีโอ **ต้นฉบับ** ก่อนนำไปใช้จริงในเว็บไซต์ แยกตามประเภทให้แล้ว —
แค่เอาไฟล์ไปวางในโฟลเดอร์ที่ตรงกับหมวดได้เลย ไม่ต้องรอ resize/ตั้งชื่อให้สวยก่อน (ขั้นตอนนั้นทำทีหลังตอนเอาขึ้นเว็บจริง)

**สำคัญ**: โฟลเดอร์นี้ไม่ถูก commit ไฟล์ภาพ/วิดีโอจริงเข้า git (กัน repo บวมและ clone ช้า — ไฟล์วิดีโอเดียวอาจหลายร้อย MB)
เฉพาะ README ของแต่ละโฟลเดอร์เท่านั้นที่ถูก track ไว้ ไฟล์สื่อจริงอยู่บนเครื่องคุณเท่านั้นจนกว่าจะพร้อมเอาขึ้น production
(ดูหัวข้อ "ไฟล์ใหญ่ไปไหน" ด้านล่าง)

## แยกตามโฟลเดอร์

| โฟลเดอร์ | ใส่อะไร | ใช้ตรงไหนในเว็บ |
|---|---|---|
| `trainers/` | ภาพเทรนเนอร์แต่ละคน (หน้าตรง + บุคลิก) | การ์ดโปรไฟล์เทรนเนอร์, หน้า "ทีมงาน" |
| `equipment/` | ภาพเครื่องออกกำลังกาย/อุปกรณ์ในยิม | การ์ดคลาส, หน้าแนะนำสิ่งอำนวยความสะดวก |
| `individual/` | ภาพเดี่ยว (คนออกกำลังกาย, แอ็กชัน, ก่อน-หลัง) | Hero/แบนเนอร์, แกลเลอรี, โซเชียล |
| `facility/` | ภาพบรรยากาศ/สถานที่ภาพรวม (ถ่ายกว้าง) | พื้นหลัง Hero, หน้า "เกี่ยวกับเรา" |
| `videos/` | คลิปวิดีโอทุกประเภท | วิดีโอพื้นหลัง Hero, คลิปโปรโมท, แนะนำคลาส |

อ่านรายละเอียดสเปก/วิธีตั้งชื่อไฟล์ในแต่ละโฟลเดอร์ย่อย (มี `README.md` อธิบายเฉพาะของมันเอง)

## ภาพรวม spec (จำง่ายๆ)

- **ถ่ายมาสูงสุดเท่าที่กล้องทำได้เสมอ** — ไฟล์ต้นฉบับความละเอียดสูงไว้ก่อน ตอนเอาขึ้นเว็บค่อยลดขนาด/บีบอัดทีหลัง
  (ลดคุณภาพจากไฟล์เล็กแล้วขยายทีหลังทำไม่ได้ แต่ลดจากไฟล์ใหญ่ทำได้เสมอ)
- ฟอร์แมตภาพต้นฉบับ: JPG หรือ HEIC ก็ได้ (ไม่ต้องแปลงเอง — ตอนขึ้นเว็บจะแปลงเป็น WebP/AVIF ให้อัตโนมัติ)
- ฟอร์แมตวิดีโอต้นฉบับ: ไฟล์จากกล้อง/มือถือตรงๆ ได้เลย (MOV, MP4) ไม่ต้องบีบอัดเอง
- **แนวภาพ**: ถ่ายทั้งแนวนอนและแนวตั้งถ้าเป็นไปได้ — เว็บต้องใช้ทั้งคู่ (แนวนอนสำหรับ desktop hero, แนวตั้งสำหรับมือถือ/โซเชียล)

## ตั้งชื่อไฟล์ยังไง

รูปแบบ: `<หมวด>-<รายละเอียดสั้นๆ>-<เลขลำดับ>.<นามสกุล>` ตัวอย่าง:
```
trainers/trainer-ake-portrait-01.jpg
equipment/equipment-squat-rack-01.jpg
individual/individual-boxing-action-03.jpg
videos/video-class-muaythai-promo.mp4
```
ไม่ต้องเป๊ะมาก แค่ให้พอเดาได้ว่าไฟล์ไหนคืออะไรตอนมีเป็นร้อยไฟล์ — ชื่อไทยก็ได้ถ้าสะดวกกว่า

## ไฟล์ใหญ่ไปไหน (วิดีโอโดยเฉพาะ)

วิดีโอไม่ควรฝังเป็นไฟล์ในเว็บโดยตรง (โหลดช้า, เปลืองพื้นที่/แบนด์วิดท์) ตัวเลือกตอนพร้อมใช้งานจริง:
1. **อัปโหลดขึ้น Supabase Storage** (มี bucket พร้อมใช้อยู่แล้วในโปรเจกต์นี้) แล้วฝังด้วย `<video>` tag — เหมาะกับคลิปสั้น (<30 วินาที, พื้นหลัง hero)
2. **ฝัง YouTube/Vimeo แบบ unlisted** — เหมาะกับคลิปยาว (แนะนำคลาส, สัมภาษณ์เทรนเนอร์) เพราะมี CDN/adaptive streaming ให้ฟรี ไม่ต้องจัดการเอง
3. ไม่ว่าทางไหน ให้บีบอัดเหลือ ~1080p, ใช้ H.264 (.mp4) เป็นหลัก ก่อนอัปโหลด

รายละเอียดเพิ่มเติม + เหตุผลเบื้องหลัง อยู่ในเอกสาร "แนวทางพัฒนาเว็บไซต์" ที่เตรียมไว้แยกต่างหาก
