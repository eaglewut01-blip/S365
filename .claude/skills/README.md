## สถานะ

โฟลเดอร์สกิลยังไม่ได้ commit ลงรีโป เพราะรีโปนี้เป็นสาธารณะ รอเจ้าของตัดสินใจก่อน
ถ้าเปิดห้องใหม่แล้วไม่เจอโฟลเดอร์สกิล ให้ขอไฟล์ `skills.zip` จากเจ้าของ แล้วก๊อปเฉพาะ 8 ตัวในตารางมาไว้ที่นี่

## กติกา

- ห้ามแก้เนื้อหาสกิลในโฟลเดอร์นี้ ฉบับจริงคือฉบับกลางในเครื่องคอม
- ถ้าต้องปรับให้เข้ากับงานของห้องนี้ ให้เขียนไว้ใน `CLAUDE.md` ที่รากโปรเจกต์
- เมื่อฉบับกลางเปลี่ยน ให้ก๊อปโฟลเดอร์สกิลนั้นมาทับทั้งโฟลเดอร์ แล้วแก้เวอร์ชันและวันที่ในไฟล์นี้
